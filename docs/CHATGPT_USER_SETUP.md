# Connect Ruddur to ChatGPT

Install Ruddur from the ChatGPT app marketplace, or add `https://mcp.ruddur.com/mcp` as a custom MCP connector where supported. The first Ruddur call opens Ruddur in your browser. Sign in and approve the requested creator permissions.

No local process, `.env` file, or pasted API token is required. If authorization fails, remove the Ruddur connection, reconnect it, and confirm that browser cookies are enabled for `ruddur.com`.
